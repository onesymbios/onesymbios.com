# Symbios website instructions

Symbios website means the public production site https://symbiosculture.com, hosted on Netlify from this repository. Do not edit a ChatGPT Sites mirror.

Before every Symbios design change, consult the current Symbios Brand Kit.html in the Symbios Google Drive: https://drive.google.com/file/d/1muR8Xn8T8wEedOzjiXerTnB_Gg_tzp2d/view . Kyle explicitly requires this. Do not approximate logos, typefaces, or colors from screenshots.

For the S mark consult the companion source generator: https://drive.google.com/file/d/1x2wmFlmWXVfLAaxsq-VlEY8T1Ddaddu3/view . It uses Lato-Light.ttf, not a hand-drawn S. The header uses the actual Lato Light glyph outline and generator dot proportions, with the circle omitted per Kyle's approved header trial. Keep the wordmark uppercase and letter-spaced using the kit's system-sans stack.

Current generator dot colors, left to right: light #2E6BFF / #C44A18 / #47739F; dark #7FA6FF / #FF8C5A / #A8C6E8. Re-read the authoritative source before future changes in case it has changed.
