# onesymbios.com

The Symbios marketing site. Static HTML, no build step, no dependencies.

## What is here

```
index.html            homepage
launch/index.html     launch animation
representation/       Symbios Representation app
og-image.png          social share image
netlify.toml          Netlify config (publish root, no build command)
```

## Deploys

Netlify builds this repo and publishes it to https://onesymbios.com.
Every push to `main` goes live. There is nothing to install and nothing to compile.

## Editing

Pages are single self-contained HTML files with inline CSS and JS.
Open one, change it, commit it.
